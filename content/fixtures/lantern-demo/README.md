# Lantern Demo Fixture

이 폴더는 BookPack 반복 제작성과 자산 이식성을 검증하는 비공개 창작 fixture다. 공개 catalog에는 노출하지
않는다. JSON은 `packages/test-book-factory`의 fixture registry와 장면 ID에서 생성한다.

```powershell
npm run content:sync
```

JSON을 직접 수정하지 않는다. `assets/`의 SVG는 외부 원본을 사용하지 않은 base와 detail fixture다. 이
이야기는 실제 문화유산, 기관, 인물에 관한 사실을 주장하지 않는다.
