# Child Study Safety Boundary

확인일: 2026-08-11

현재 실제 아동 연구는 승인되지 않았고 수집량은 0이다. 보호자 동의, 아동의 이해 가능한 참여 의사,
연구 책임자, 개인정보 책임자, 최소 수집, 보존 기간, 삭제 절차와 사고 대응이 승인 기록으로 결박되기
전에는 아동을 모집하거나 제품을 시험시키거나 데이터를 기록하지 않는다.

## 연구가 답할 수 있는 범위

승인 뒤 첫 사용성 연구는 시작 행동 발견, 세 길의 단서 비교, 재시도, 이야기와 현실 질문 카드의 구분,
압박 없는 마무리 선택만 관찰한다. 교육 효과, 장기 독해 향상과 문화 지식 향상은 이 연구의 판정 범위가
아니다.

## 참여와 중단

- 보호자 동의와 별도로 아이가 이해할 수 있는 말로 참여 의사를 확인한다.
- 아이가 말이나 몸짓으로 거부하거나 피로, 불안, 반복 실패, 보호자 요청 또는 기술 오류가 생기면 즉시
  중단한다.
- 학교 성적, 진단, 불이익이나 제품 보상과 참여를 연결하지 않는다.
- 연구자는 요청 전 정답이나 제어 위치를 알려 주지 않고 승인된 중립 질문만 사용한다.

## 최소 수집과 분리

승인 전에는 어떤 연구 데이터도 수집하지 않는다. 승인 뒤에도 이름과 연락처를 제품에 저장하지 않고,
자유 답안 원문, 음성, 영상, 정확한 시각과 포인터 궤적은 기본 수집하지 않는다. 필요한 관찰은 세션 단위의
첫 막힘 단계, 넓은 기기 종류와 접근성 설정, 개인 식별 내용을 제거한 보호자 요약으로 제한한다.

식별 가능한 동의 원본과 연구 기록은 서로 다른 접근 권한으로 분리한다. public repository, GitHub issue,
스크린샷과 앱 `localStorage`에는 넣지 않는다.

## 보존, 철회와 삭제

보존 기간과 삭제 SLA는 승인자가 목적에 필요한 최소값으로 정한다. 동의 전에 철회와 삭제 요청 경로를
제공하고 삭제 실행자, 삭제 범위, 백업 반영 시점과 완료 증거를 기록한다. 연구 종료 또는 중단 시 미사용
원자료 삭제와 집계 보존 여부를 개인정보 책임자가 판정한다.

## OPERATOR GATE

`OG-06` 승인 기록에는 다음 항목이 모두 필요하다.

1. 연구 책임자와 개인정보 책임자
2. 모집 수, 장소, 보상과 이해상충
3. 보호자 동의문과 아동 동의문
4. 수집 항목, 저장 위치, 접근자, 보존 기간과 삭제 SLA
5. 사고, 불편, 민원과 철회 대응
6. 결과가 확장, 개선, 수리, 철회 중 어떤 판정에 쓰이는지
7. 실제 문화자산과 음성의 권리, 문화, 교육 승인 상태

이 일곱 항목이 대상 commit과 protocol version에 결박되기 전에는 연구를 시작하지 않는다. 자동 테스트와
기술 검수는 `OG-06`을 대신 승인하지 않는다.
