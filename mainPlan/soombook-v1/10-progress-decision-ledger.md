# 10. Progress and Decision Ledger

상태: 활성 원장

완료된 구현 꼭지의 설명과 검증 결과는 `docs/**`의 현재 계약과 코드, 테스트가 소유한다. 이 원장에는
완료 이력을 쌓아 두지 않고, 아직 닫히지 않은 한 꼭지와 운영자 권한이 필요한 외부 gate만 남긴다.

## 현재 요약

| 필드 | 현재 값 |
|---|---|
| Primary goal ID | `completeMeaningfulStoryJourney` |
| 현재 Phase | `P1 cross-engine device matrix 자동 검수` |
| 현재 제품 | 공개 4장면 수직 절편, 내부 5장면 fixture, 비공개 10장면 review 후보, 정적 PWA |
| 현재 자동화 | BookPack 전체 파일 결박, 권리 승인 경계, PWA 두 버전 갱신, 대표작 기술 promotion |
| 현재 손실 전이 | 10장면 후보의 cross-engine 접근성 구조와 기기 모의 증거가 전문 검수 quorum까지 닫히지 않음 |
| 원격 상태 | `main` 최초 push 준비 |
| NEXT | 8-profile device matrix의 current-scope aggregate와 전문 에이전트 영수증 완성 |

## 현재 확인 사실

- Chromium, Firefox, WebKit, 200% CSS root scale, forced-colors, reduced-motion, high-contrast와 touch 모의
  profile의 실행기와 receipt 형식이 있다.
- 대표작 후보의 source, plan, build artifact, 상태 투영, offline 완료와 진행 저장을 같은 matrix 입력으로
  결박한다.
- 정적 contract, typecheck, lint, format과 project registry는 통과한다.
- 접근성 tree의 exact progress label, raw role cardinality, non-retry live event, 상충하는 공개 승격 문구와
  expert receipt commitment에 아직 재현 가능한 우회가 있다.
- 따라서 현재 device matrix 꼭지는 완료로 기록하지 않고 `NEXT`에 유지한다.

## 현재 결정

1. 완료된 권리 자동화, PWA 복구, BookPack 결박과 대표작 promotion 꼭지는 활성 원장에서 삭제했다.
2. 기기 matrix는 실제 보조기기 승인을 가장하지 않는 자동 구조와 browser emulation 증거로 한정한다.
3. current scope의 8개 profile과 세 전문 에이전트 PASS가 모두 없으면 이 꼭지를 닫지 않는다.
4. 완료 뒤 확인된 현재 계약만 `docs/**`에 반영하고 이 `NEXT`를 삭제한다.

## NEXT

`8-profile device matrix의 exact 접근성 투영, current-scope aggregate와 세 전문 에이전트 quorum`을
완성한다.

완료 조건:

1. 진행 단계의 이름과 상태, landmark, heading, status, reflection, truth와 공개 비승격 문구를 exact
   accessibility projection으로 검증한다.
2. raw AX role 수와 상태별 live event를 coherent receipt 변조에도 우회할 수 없게 한다.
3. Chromium, Firefox와 WebKit을 포함한 8개 profile이 새 build와 같은 scope에서 통과한다.
4. engine compatibility, interaction persistence, accessibility structure 담당 전문 에이전트가 서로 다른
   reviewer ref로 같은 candidate와 matrix evidence를 PASS한다.
5. 검증 결과를 현재 계약에 반영한 뒤 이 `NEXT`를 삭제한다.
