# 02. Experience, Content, and Pedagogy

상태: V1 경험 계약 v1.0

범위: 4장면 수직 절편의 이야기, UI 상태, 상호작용, 읽기 지원, 교육 의도와 콘텐츠 제작 기준.

## 1. 경험 목표

첫 세션이 끝났을 때 아이에게 남아야 하는 것은 다음 네 문장이다.

1. 나는 책을 스스로 열었다.
2. 글과 그림을 같이 봐야 단서를 찾을 수 있었다.
3. 호랑이가 떠난 이유를 단서로 설명할 수 있다.
4. 이야기 속 물건과 실제 문화유산은 연결되지만 같은 것은 아니다.

반대로 다음 기억만 남으면 실패다.

- 돋보기를 움직였다.
- 발자국을 빨리 찾았다.
- 애니메이션이 신기했다.
- 버튼을 눌러 다음 화면으로 갔다.

## 2. 첫 세션 시간 예산

| 구간 | 목표 범위 | 상한 이유 |
|---|---:|---|
| 랜딩과 표지 열기 | 20~45초 | 제품 설명보다 행동으로 시작 |
| 장면 1 | 60~90초 | 사건 인지 |
| 장면 2 | 90~150초 | 읽기와 빈자리 관찰 |
| 장면 3 | 150~240초 | 핵심 단서 탐색과 힌트 |
| 장면 4 | 90~180초 | 추론, 연결 카드, 완주 |
| 전체 | 6~10분 | 4장면 prototype 가설 |

이 시간은 아이를 재촉하는 타이머가 아니다. 제작 분량과 성능을 제어하는 내부 예산이다.

## 3. 정보 구조

### 3.1 V1 공개 표면

```text
입구
├─ 오늘의 책 열기
├─ 이어 읽기, 로컬 진행이 있을 때만
└─ 보호자 안내

책
├─ 표지
├─ 장면 1~4
├─ 읽기 도구
├─ 탐험 도구
├─ 보물함
└─ 완주

보호자 안내
├─ 제품 목적
├─ 실제 자산과 fixture 구분
├─ 출처와 이용조건
├─ 데이터 저장 내용
├─ 데이터 삭제
└─ 외부 링크
```

책장, 검색, 지도, 계정, 구독은 V1 내비게이션에 자리만 만들지 않는다. 보이지 않는 빈 메뉴는 제품 범위가
아니다.

### 3.2 아이 화면 도구

| 물건 메타포 | 기능 | 표준 제어 대체 |
|---|---|---|
| 책 모서리 | 이전, 다음 장면 | 이전·다음 버튼, 화살표 키 |
| 연필 | 읽기 모드와 오디오 | 명시적 mode button group |
| 황동 렌즈 | 세부 확대와 단서 탐색 | 영역 목록, 탭 탐색, 키보드 탐색 |
| 책갈피 | 현재 장면과 이어 읽기 | progress label과 장면 목록 |
| 보물함 | 찾은 핵심 단서 | 발견 목록 |

메타포만 보고 기능을 알 수 없는 사용자를 위해 accessible name과 짧은 label을 항상 제공한다.

## 4. 4장면 이야기 계약

### 장면 1. 봉인된 책

**이야기 목적**

밤의 기록관에게서 도착한 책을 아이가 직접 열고, 그림에서 무언가 사라졌다는 사건을 인지한다.

**화면**

- 어두운 나무 책상
- 닫힌 천 표지 책
- 표지에 눌린 발자국 한 개
- 약한 빗소리, 무음 설정에서는 없음

**본문 초안**

```text
밤이 되자 기록관의 책상 위로 낯선 책 한 권이 도착했어요.
표지에는 제목 대신 커다란 발자국만 남아 있었지요.
책을 열자, 그림 속에서 무언가 사라졌다는 편지가 나왔어요.
```

**필수 행동**

- 책 열기

**대체 경로**

- 표지 drag
- `책 열기` tap
- Enter 또는 Space

**학습 요소**

- 사건의 시작과 예측
- 표지 단서 관찰

**완료 조건**

표지 열기 animation의 성공 여부가 아니라 장면 1 내용이 읽기 가능한 상태로 확정됐을 때다.

### 장면 2. 비어 있는 그림

**이야기 목적**

그림의 빈자리를 보고 호랑이가 원래 있었음을 글과 그림으로 추론할 준비를 한다.

**화면**

- 산과 소나무가 있는 그림
- 호랑이 자리의 눌린 풀과 빈 윤곽
- 처음에는 렌즈가 필요 없는 전체 관찰

**본문 초안**

```text
그림에는 산도 나무도 그대로였지만, 한가운데가 이상하게 비어 있었어요.
풀은 커다란 몸이 누웠던 것처럼 한쪽으로 쓰러져 있었지요.
기록관의 편지에는 이렇게 적혀 있었어요. "사라진 주인을 찾아 주세요."
```

**핵심 어휘**

- 흔적: 어떤 일이 있었음을 알 수 있게 남은 것

**필수 행동**

없음. 첫 읽기에서 상호작용을 연속으로 요구하지 않는다.

**선택 행동**

- 빈자리 확대
- `무엇이 있었을까` 예측 선택

**학습 요소**

- 명시 정보와 그림 정보 결합
- 다음 장면 예측

### 장면 3. 세 발자국

**이야기 목적**

새, 고양이, 호랑이 발자국을 비교하고 본문 단서로 호랑이 흔적을 찾는다.

**화면**

- 젖은 마룻바닥
- 서로 다른 세 발자국
- 기본 이미지에는 모양이 보이지만 세부 패드는 렌즈에서 더 선명함

**본문 초안**

```text
젖은 바닥에 서로 다른 발자국 세 줄이 남아 있었어요.
하나는 가볍고 뾰족했고, 하나는 작고 둥글었어요.
가장 큰 발자국에는 넓은 발바닥과 둥근 발가락이 보였지요.
```

**핵심 어휘**

- 짐작: 보거나 들은 것을 바탕으로 생각해 보는 것

**필수 행동**

- 호랑이 발자국 찾기

**힌트 사다리**

1. `본문에서 크기와 모양을 말한 부분을 다시 들어 볼까?`
2. `세 발자국의 발가락 모양을 비교해 봐.`
3. 바닥을 세 영역으로 나눠 넓게 강조한다.
4. 호랑이 발자국 주위에 연필 원을 그린다.

**대체 경로**

- 렌즈 이동 뒤 hotspot 선택
- 세 영역 중 하나 tap
- 발자국 확대 카드 세 장을 차례로 탐색
- 키보드로 세 후보를 이동하고 선택
- 스크린리더 목록에서 설명을 듣고 선택

**정답 피드백**

```text
넓고 둥근 발자국이 그림 밖을 향하고 있어요.
호랑이는 누군가에게 끌려간 것이 아니라 스스로 걸어 나간 것 같아요.
```

**오답 피드백**

```text
이 발자국도 자세히 볼 가치가 있어요.
본문에서 "가장 큰"이라고 한 부분과 다시 비교해 볼까요?
```

오답 횟수와 성공 속도를 점수로 저장하지 않는다.

### 장면 4. 떠난 이유와 현실 연결

**이야기 목적**

앞 장면의 빈자리, 발자국과 풀잎을 근거로 호랑이가 그림 밖 솔향기가 궁금해 스스로 걸었다는 창작 사건을
정리하고, 이야기와 실제 소장품 source 후보의 경계를 확인한다.

**본문 초안**

```text
호랑이는 잡혀간 것이 아니었어요. 그림 밖 솔향기가 궁금해 제 발로 걸어 나갔지요.
숨이는 호랑이를 억지로 데려오지 않았어요. 호랑이는 궁금한 것을 보고 스스로 돌아가기로 했어요.
이 사건은 숨책이 만든 이야기이며 실제 소장품의 역사나 작가 의도가 아니에요.
```

**필수 행동**

- 이유 선택 또는 `단서 다시 보기`
- 연결 카드 열기

**추론 선택지**

- 누군가가 억지로 데려갔다.
- 스스로 그림 밖으로 걸어 나갔다.
- 처음부터 호랑이는 없었다.

정답 뒤에 `발자국이 그림 밖을 향했다`는 근거를 함께 보여준다.

**연결 카드 상태**

- 개발 fixture: `실제 유물 아님`, `기능 검증용 직접 제작 이미지`
- 실제 승인 자산: 소장품명, 기관, 시대, 쉬운 설명, 원문, 공공누리, 변경 내용, 확인일

**완주 질문**

```text
호랑이는 왜 그림 밖으로 나갔을까?
```

V1의 입력 선택:

- 준비된 근거 문장 중 하나 선택
- 보호자에게 말해 보기 선택
- 건너뛰기

마이크와 자유 텍스트 저장은 없다.

## 5. 장면 상태 기계

```text
idle
-> entering
-> readable
-> narrating
-> explorable
-> clueFound
-> reasoning
-> connected
-> readyToLeave
-> leaving
```

### 불변조건

- `readable` 전에 필수 찾기를 활성화하지 않는다.
- `narrating`과 `leaving`을 동시에 유지하지 않는다.
- `clueFound`는 input 방식과 무관하게 같은 command로 확정한다.
- 장면을 나간 뒤 이전 audio와 pointer capture를 남기지 않는다.
- 돌아온 장면은 확정된 단서를 다시 숨기지 않되 재탐험을 허용한다.
- 오류는 `readable` 정적 fallback을 유지한다.

## 6. 읽기 지원 설계

### 6.1 모드

| 아이 문구 | 동작 | 자동화 한계 |
|---|---|---|
| 내가 읽을래 | 음성 없이 본문 표시 | 자동 넘김 없음 |
| 같이 읽자 | segment 하이라이트와 음성 | 장면 끝에서 대기 |
| 들려줘 | 전체 문장을 듣고 그림에 집중 | 상호작용은 문장 끝 뒤 열림 |

### 6.2 지원 수준

난이도 꼬리표 대신 기능 조합을 쓴다.

| 지원 preset | 기본 기능 |
|---|---|
| 가벼운 도움 | 핵심 어휘 표시, 요청 시 음성 |
| 함께 읽기 | 하이라이트, 낭독, 문장 replay |
| 많이 도와주기 | 짧은 문장 분리, 힌트 제안 |
| 자유 탐험 | 자동 제안 최소화, 필요 시 도구 사용 |

아이의 수준을 추론해 `낮음`, `느림`, `뒤처짐`으로 표시하지 않는다.

### 6.3 단어 돋보기

각 단어는 다음 세 층을 가진다.

1. 초3 수준 한 문장 뜻
2. 현재 장면 예문
3. 이미지, 행동, 실제 사물 연결

단어 카드는 본문 문맥을 가리지 않고 닫은 뒤 같은 문장 위치로 돌아온다. 단어 시험과 연속 출석으로
변형하지 않는다.

## 7. 상호작용 문법

### 7.1 허용하는 필수 행동

- 서사 단서: 사건을 이해하는 흔적
- 관찰 단서: 앞뒤 장면 차이를 설명하는 요소
- 문화 단서: 실제 사물이나 문화유산으로 연결되는 요소

장식 수집물은 첫 읽기 필수 행동으로 두지 않는다.

### 7.2 행동 예산

| 책 단계 | 장면당 필수 | 장면당 선택 | 이유 |
|---|---:|---:|---|
| 4장면 prototype | 0~1 | 0~1 | 핵심 루프 검증 |
| 첫 완전한 책 | 0~1 | 0~2 | 읽기 흐름 보존 |
| 재독 | 0 | 0~3 | 발견 가치 확장 |

### 7.3 조작 우선순위

1. 현재 장면의 주 행동
2. 읽기와 음성
3. 이전·다음
4. 보물함과 장면 목록
5. 설정과 보호자 안내

동시에 세 개 이상의 강조 버튼을 두지 않는다.

## 8. 페이지 물성과 모션

### 8.1 필수 물성

- 표지와 내지의 두께 차이
- 전환 중 앞면과 뒷면의 명확한 관계
- 과도하지 않은 그림자
- 손을 놓았을 때 commit 또는 cancel이 예측 가능함

### 8.2 progressive enhancement

| 등급 | 동작 | 사용 조건 |
|---|---|---|
| A | 곡률과 앞뒤 면이 있는 전환 | 충분한 성능, motion 허용 |
| B | 짧은 fold 전환 | 중간 성능 |
| C | opacity와 translate 최소 전환 | 저사양 또는 motion 감소 |
| D | 즉시 정적 전환 | 접근성 설정 또는 오류 fallback |

기기 모델을 하드코딩하지 않는다. 측정한 frame budget과 사용자 설정으로 선택한다.

## 9. 시각과 소리 시스템

### 9.1 시각 토큰

- 재료: 한지, 천, 수채화, 연필, 잉크, 황동, 오래된 나무
- 빛: 따뜻한 자연광, 약한 밤 조명
- 형태: 장난감 버튼보다 도구, 단 accessible affordance는 숨기지 않음
- 강조: 잉크 번짐, 연필 윤곽, 종이 조각

### 9.2 금지

- 네온 HUD
- 코인, 보석, 레벨 게이지
- 계속 흔들리는 CTA
- 성공마다 폭죽
- 캐릭터가 정답을 대신 말함
- 전체 화면을 막는 장문 튜토리얼

### 9.3 음향 예산

- 표지 마찰음
- 종이 전환음
- 연필선
- 렌즈를 놓는 작은 금속음
- 짧은 비와 실내 잔향

상시 음악은 기본으로 사용하지 않는다. 음성보다 배경음이 커지지 않으며 완전 무음이 가능해야 한다.

## 10. 교육 설계

### 10.1 V1 목표 역량

| 역량 | 4장면에서의 증거 |
|---|---|
| 유창한 읽기 | 직접 읽기와 낭독을 전환하며 문장을 끝냄 |
| 어휘 | `흔적`, `짐작`을 장면 예로 이해 |
| 독해 | 빈자리와 발자국 문장을 결합 |
| 추론 | 그림 밖 방향으로 스스로 떠났다고 판단 |
| 시각 문해 | 세 발자국의 크기와 형태를 비교 |
| 표현 | 사건 원인을 한 문장으로 선택하거나 말함 |
| 배경지식 | 실제 옛 그림과 허구 장면의 관계를 구분 |

### 10.2 질문 규칙

- 장면당 평가 질문은 최대 1개다.
- 질문 전에 필요한 본문과 이미지 근거가 있다.
- 오답은 사람 능력 평가가 아니라 근거를 다시 보게 하는 상태다.
- 열린 질문은 여러 타당한 답을 허용한다.
- 사실 지식보다 먼저 관찰과 근거를 묻는다.

### 10.3 다시 읽기

V1에서도 재독 상태를 설계하되 추가 콘텐츠 제작은 최소화한다.

- 첫 읽기: 필수 이야기와 발자국 한 개
- 두 번째 읽기: 빈자리 스케치, 다른 발자국 설명, 렌즈 자유 탐색
- 세 번째 이후: 장면 바로 가기와 보물 다시 보기

재독 보상은 새 점수가 아니라 이전에 보지 못한 관점이다.

## 11. 콘텐츠 제작 순서

1. 장면 목적 한 문장 작성.
2. 아이가 마지막에 말할 이해 한 문장 작성.
3. 본문 없이도 보이는 시각 정보와 본문에서만 알 수 있는 정보를 분리.
4. 필수 행동이 이해에 필요한지 판정.
5. 본문 초안과 핵심 어휘 작성.
6. 정답, 오답, 힌트, 대체 탐색 문구 작성.
7. 허구 claim과 사실 claim 분리.
8. 직접 제작 fixture asset 연결.
9. 낭독과 segment fixture 연결.
10. 교육, 문화, 권리, 접근성 검토 상태 기록.
11. BookSpec validator 통과.
12. 브라우저와 실제 기기 검수.

## 12. 사람 검토 rubric

각 축은 `승인`, `수정`, `차단` 중 하나로 판정한다.

| 축 | 질문 | 차단 예시 |
|---|---|---|
| 이야기 | 다음 장면을 궁금해하는가 | 행동 없이 설명만 이어짐 |
| 초3 언어 | 유치하지 않고 이해 가능한가 | 긴 추상어 연속, 아기 말투 |
| 행동 의미 | 행동이 이해를 깊게 하는가 | 무관한 물건 수집 |
| 감정 안전 | 두려움과 실패를 과도하게 쓰지 않는가 | 벌, 비난, 시간 압박 |
| 문화 정확성 | 사실과 창작을 구분했는가 | 시대, 용도, 소장 정보 오기 |
| 권리 | 모든 asset 사용과 변경이 허용되는가 | URL만 있고 이용조건 없음 |
| 접근성 | 대체 경로가 같은 결과를 주는가 | 장면 설명만 있고 단서 완료 불가 |

## 13. 아동 사용성 관찰 항목

실제 연구는 승인 뒤 수행하며 다음을 관찰한다.

- 표지와 첫 CTA를 설명 없이 찾는가.
- 읽기 모드를 자신의 의도로 고르는가.
- 본문을 읽거나 듣기 전에 찾기만 시도하는가.
- 렌즈와 페이지 넘김이 충돌하는가.
- 단어 뜻을 자신의 말로 바꾸어 말할 수 있는가.
- 힌트가 도움인지 실패 표시인지 어떻게 받아들이는가.
- 호랑이가 떠난 이유와 그 근거를 연결하는가.
- fixture 또는 삽화와 실제 유물을 혼동하는가.
- 완주 뒤 다시 보고 싶은 장면을 고르는가.
- 중단, 피로, 멀미, 불안 신호가 있는가.

`재미있었니`라는 한 질문으로 성공을 판정하지 않는다. 행동, 회상, 오해, 정서 반응을 함께 본다.
