# 00. Product PRD

상태: 구현 착수 계약 v1.0

작성 기준일: 2026-08-09

제품 작업명: 숨책, Soombook

## 1. 제품 결정

숨책은 많은 전자책을 보여주는 서비스가 아니다. 초등학교 3학년 아이가 한 장면을 읽고, 이야기와 관련된
단서를 찾고, 그 단서로 이유를 생각하고, 실제 문화유산 또는 현실의 사물과 연결하는 짧은 독서 탐험
런타임이다.

```text
읽기 -> 찾기 -> 추론하기 -> 연결하기 -> 자기 말로 남기기
```

첫 배포 판단은 카탈로그 수, 계정 수, 체류시간으로 하지 않는다. 아이가 어른의 조작 설명 없이 위 루프를
완주하고 이야기의 원인을 근거와 함께 회상할 수 있는지로 판단한다.

## 2. 문제와 기회

### 2.1 아이의 문제

- 읽기는 과제처럼 느껴지고, 디지털 콘텐츠는 이야기보다 자극이 앞서는 경우가 많다.
- 모르는 단어 하나가 전체 장면 이탈로 이어진다.
- 그림을 자세히 보는 행동이 확대 외에는 제품 의미로 연결되지 않는다.
- 읽어주기는 수동 재생이 되기 쉽고, 찾기 게임은 글을 건너뛰게 만들기 쉽다.
- 박물관 정보는 풍부하지만 아이가 감정적으로 진입할 서사 입구가 부족하다.

### 2.2 보호자의 문제

- 영상과 게임을 대체하면서도 아이가 자발적으로 시작할 안전한 경험이 부족하다.
- 읽은 시간과 권수만으로는 아이가 무엇을 이해했는지 알 수 없다.
- 가입, 광고, 행동 추적, 콘텐츠 품질과 출처를 신뢰하기 어렵다.

### 2.3 교사와 기관의 문제

- 좋은 문화유산 자료를 짧은 수업 활동으로 재구성하는 비용이 높다.
- 영상 시청과 정답 퀴즈를 넘어 관찰과 근거 말하기를 유도할 도구가 부족하다.
- 학생 계정과 개인정보 관리가 도입 장벽이다.

### 2.4 제품 기회

숨책은 박물관 데이터베이스, 일반 전자책, 학습지 중 하나를 대체하지 않는다. 이야기가 문화유산으로
들어가는 입구가 되고, 문화유산이 다음 독서의 단서가 되는 연결층을 만든다.

## 3. 사용자와 우선순위

| 순위 | 사용자 | 해야 할 일 | 첫 제품이 주는 결과 |
|---:|---|---|---|
| 1 | 초등학교 3학년 아이 | 설명 없이 책을 열고 읽으며 의미 있는 행동을 하고 싶다 | 10분 이내 4장면 완결 탐험 |
| 2 | 보호자 | 안전하게 맡기고 아이와 책 이야기를 이어가고 싶다 | 무계정 사용, 쉬운 출처, 대화 단서 |
| 3 | 콘텐츠 편집자 | 장면, 음성, 단서, 권리를 반복 가능한 형식으로 만들고 싶다 | 검증 가능한 BookSpec과 출판 게이트 |
| 4 | 교사 | 계정 부담 없이 읽고 찾고 근거를 말하는 수업을 하고 싶다 | V1 검증 후 별도 파일럿 |
| 5 | 박물관 담당자 | 소장품을 정확하고 매력적인 서사로 연결하고 싶다 | 권리와 정확성 승인 뒤 별도 제휴 |

V1의 구매자와 최종 사용자를 혼동하지 않는다. 보호자가 결제하더라도 제품의 주 사용 여정은 아이가
독립적으로 완주해야 한다.

## 4. 핵심 가설

### H1. 의미 있는 행동 가설

아이에게 이야기 이해에 필요한 관찰 행동을 주면 수동 낭독보다 자발적 읽기와 회상이 늘어난다.

반증 조건:

- 대부분의 아이가 본문을 건너뛰고 단서만 반복한다.
- 단서 찾기 성공 여부와 이야기 회상 사이에 관계가 없다.
- 상호작용 없는 정적 읽기 버전이 완주와 회상에서 더 낫다.

### H2. 감성 물성 가설

책, 종이, 렌즈, 연필이라는 물성 메타포가 초3에게 유치하지 않으면서 조작 발견을 돕는다.

반증 조건:

- 애니메이션이 시작 시간을 늦추거나 멀미와 혼란을 만든다.
- 표지 열기와 페이지 넘김을 설명 없이 수행하지 못한다.
- 단순 전환 버전이 감성 손실 없이 더 높은 완주율을 보인다.

### H3. 현실 연결 가설

이야기 직후 실제 유물의 쉬운 출처 카드를 보면 장면 회상과 박물관 관심이 늘어난다.

반증 조건:

- 카드가 이야기 흐름을 끊는다.
- 아이가 삽화와 실제 유물의 관계를 오해한다.
- 보호자가 기관 제휴 또는 공식 콘텐츠로 잘못 이해한다.

## 5. 제품 결과 계약

### 5.1 Primary goal

`completeMeaningfulStoryJourney`

아이의 의도적 시작 하나가 다음 상태를 순서대로 지나 완결되는 결과다.

```text
opened -> read -> explored -> reasoned -> connected -> completed
```

| 상태 | 진입 조건 | 대체할 수 없는 증거 |
|---|---|---|
| `opened` | 아이가 표지 또는 시작 버튼을 직접 눌러 첫 장면을 봄 | 랜딩 노출은 제외 |
| `read` | 핵심 문장을 직접 진행하거나 승인된 낭독을 끝까지 들음 | 음소거 자동 재생은 제외 |
| `explored` | 필수 단서를 렌즈, 탭 대체, 키보드, 선형 탐색 중 하나로 발견 | 힌트 표시만은 제외 |
| `reasoned` | 단서에 근거한 이유를 선택하거나 말하기 준비 상태에 도달 | 무관한 정답 클릭은 제외 |
| `connected` | 출처가 있는 실제 세계 연결 카드 또는 권리 깨끗한 fixture 카드를 열어봄 | 카드 렌더만은 제외 |
| `completed` | 4장면을 마치고 한 문장 회상 또는 보물 다시 보기 중 하나를 선택 | 마지막 장면 노출만은 제외 |

V1 개발 fixture에서는 실제 아이 지표로 세지 않는다. 성인 QA, 자동 테스트, 데모 조작은 별도 origin으로
분리한다.

### 5.2 Supporting goals

- `openFirstStoryFast`: 첫 의도적 입력 후 2초 안에 읽을 수 있는 첫 장면을 보여준다.
- `understandStoryThroughEvidence`: 단서와 본문을 근거로 사건 원인을 설명할 수 있게 한다.
- `protectChildTrust`: 광고, 공개 소통, 불필요한 식별, 벌과 경쟁 없이 동작한다.
- `keepReaderResponsive`: 지원 기기에서 조작 응답과 오디오가 끊기지 않는다.
- `enableRepeatableBookProduction`: 같은 BookSpec과 검증기로 두 번째 책을 개발자 전용 편집 없이 만들 수 있게
  한다.

## 6. V1 제품 범위

### 6.1 첫 공개 후보

《호랑이가 그림에서 사라졌다》 4장면 수직 절편이다.

1. 봉인된 책을 열고 사건을 만난다.
2. 그림에서 사라진 호랑이의 빈자리를 읽는다.
3. 세 종류 발자국을 관찰하고 호랑이 단서를 찾는다.
4. 왜 호랑이가 떠났는지 추론하고 현실 연결 카드를 본다.

초기 개발은 외부 박물관 원본을 사용하지 않는다. 직접 제작한 추상 fixture 이미지와 명확한
`DEMO ASSET` 표시로 기능을 완성한다. 승인된 실제 자산은 교체 가능한 데이터다.

### 6.2 필수 기능

| ID | 기능 | 사용자 결과 |
|---|---|---|
| FR-01 | 즉시 시작 | 가입과 개인정보 입력 없이 첫 장면을 연다 |
| FR-02 | 반응형 책 보기 | PC, 태블릿, 스마트폰에서 읽을 수 있다 |
| FR-03 | 페이지 전환 | 드래그, 탭, 키보드로 같은 장면 이동이 가능하다 |
| FR-04 | 읽기 모드 | 직접 읽기, 같이 읽기, 들려주기를 전환한다 |
| FR-05 | 음성 동기화 | 문장 또는 어절 하이라이트가 검수된 타이밍을 따른다 |
| FR-06 | 탐험 렌즈 | 그림 세부와 단서를 탐색한다 |
| FR-07 | 대체 탐색 | 렌즈 드래그 없이 탭 영역, 목록, 키보드로 같은 단서를 찾는다 |
| FR-08 | 힌트 사다리 | 말, 방향, 영역, 직접 힌트를 불이익 없이 쓴다 |
| FR-09 | 근거 추론 | 찾은 단서와 사건 원인을 연결하는 짧은 선택을 한다 |
| FR-10 | 연결 카드 | 이름, 쉬운 설명, 출처, 상태를 구분해 본다 |
| FR-11 | 로컬 진행 | 새로 열어도 마지막 확정 장면과 설정을 복구한다 |
| FR-12 | 동작 줄이기 | 페이지 곡률과 이동을 단순 전환으로 바꾼다 |
| FR-13 | 완주 | 점수 없이 이야기 한 줄, 보물, 다음 예고를 본다 |
| FR-14 | 출판 차단 | schema, 권리, 접근성, 성능 오류가 있으면 공개 팩을 만들지 않는다 |

## 7. 기능 수용 기준

### FR-01 즉시 시작

- 첫 화면의 주 행동은 하나이며 `오늘의 책 열기` 또는 동등한 아동 문구다.
- 로그인, 쿠키 배너, 알림 허용, 설치 유도보다 앞선다.
- 필수 자산 실패 시 빈 화면 대신 정적 첫 장면과 다시 시도 제어를 제공한다.
- 첫 세션에서 별명 입력도 요구하지 않는다.

### FR-02 반응형 책 보기

- 1280px 이상에서는 양면 펼침을 기본으로 한다.
- 768px 안팎 가로 태블릿은 공간이 허용되면 양면, 아니면 한 면을 쓴다.
- 좁은 화면은 한 페이지와 명시적 다음, 이전 제어를 쓴다.
- 확대 200%에서도 본문과 주요 제어가 잘리거나 겹치지 않는다.
- 가로와 세로 회전 뒤 현재 장면과 읽기 상태를 보존한다.

### FR-03 페이지 전환

- 드래그는 감성 향상 경로이지 필수 경로가 아니다.
- 화면 가장자리 탭, 이전·다음 버튼, 좌우 화살표가 같은 전이를 호출한다.
- 렌즈 사용 중에는 페이지 전환 포인터 영역을 잠그되 키보드와 명시적 버튼의 상태를 사용자에게 알린다.
- 전환 중 연속 입력은 한 번만 확정되며 장면을 건너뛰지 않는다.
- 오디오 정리와 상태 저장은 전환 commit과 원자적으로 처리한다.

### FR-04 읽기 모드

- `내가 읽을래`, `같이 읽자`, `들려줘` 세 이름을 사용한다.
- 모드 전환은 현재 문장 위치를 보존한다.
- 직접 읽기에서 자동 재생하지 않는다.
- 들려주기에서도 페이지를 자동으로 넘기지 않는다.
- 새 장면의 기본 모드는 기기 로컬에 저장한 마지막 명시적 선택을 따른다.

### FR-05 음성 동기화

- 오디오는 사전 제작되고 사람 검수된 파일 또는 개발용 fixture다.
- segment는 음수가 아니고 오름차순이며 track 길이를 넘지 않는다.
- 문장을 누르면 해당 segment 시작점으로 이동한다.
- 재생 속도 변경 뒤 하이라이트가 현재 오디오 위치와 250ms 이상 지속적으로 어긋나지 않는다.
- 장면을 떠나면 이전 audio node가 정지하고 해제된다.

### FR-06, FR-07 탐험과 대체 탐색

- 렌즈를 첫 장면에서 설명문 없이 시각적 affordance로 찾을 수 있다.
- 렌즈 손잡이는 최소 44 x 44 CSS px 권장 크기를 적용한다.
- 필수 hotspot은 시각 드래그, 탭 영역 목록, 키보드 선형 탐색 중 적어도 두 경로로 도달한다.
- 정확한 좌표가 없어도 대체 경로에서 같은 서사 피드백과 진행 상태를 얻는다.
- 렌즈 고해상도 자산 실패 시 기본 이미지 확대와 대체 목록으로 계속 진행한다.

### FR-08 힌트

- 20초 정체 또는 명시적 요청 뒤 힌트를 제안할 수 있지만 자동으로 정답을 표시하지 않는다.
- 단계는 말, 방향, 영역, 직접 순서이며 건너뛰기와 다시 듣기가 가능하다.
- 힌트 사용은 점수, 잠금, 공개 기록에 불이익을 만들지 않는다.
- 이벤트에는 힌트 단계만 기록하고 정확한 포인터 위치를 기록하지 않는다.

### FR-09 근거 추론

- 질문은 `무엇`, `어디`, `왜`, `이어보기` 순서 중 장면 목적에 맞는 하나를 쓴다.
- 4장면 fixture의 추론은 세 발자국 중 호랑이 흔적을 고른 근거와 떠난 이유를 연결한다.
- 단일 정답형인 경우 오답을 빨간 실패로 표시하지 않고 단서를 다시 보게 한다.
- 열린 답변은 V1에서 서버에 저장하지 않는다. 로컬에서도 자동 저장하지 않는 것이 기본이다.

### FR-10 연결 카드

- 실제 자산이면 소장품명, 기관, 원문 URL, 이용조건, 확인일, 숨책 변경 내용을 제공한다.
- fixture이면 실제 유물이 아니며 개발용 대체 자산임을 명확히 표시한다.
- 카드에서 외부 링크를 누르면 보호자 확인 문맥으로 전환한다.
- 제휴 또는 공식 인증을 암시하는 로고와 표현을 쓰지 않는다.

### FR-11 로컬 진행

- 저장 키는 BookSpec 버전과 익명 설치 ID가 아닌 로컬 profile slot을 기준으로 한다.
- 저장 내용은 책 ID, 팩 버전, 마지막 확정 장면, 발견 ID, 읽기 설정뿐이다.
- 자유 텍스트, 음성, 정확한 행동 시각, 실제 이름은 저장하지 않는다.
- 데이터 삭제 제어는 첫 버전부터 제공한다.
- BookSpec 호환 불가 변경은 안전한 migration 또는 진행 초기화 안내를 사용한다.

### FR-12 동작 줄이기

- `prefers-reduced-motion`이 켜져 있으면 최초 진입부터 단순 전환을 쓴다.
- 설정에서 언제든 바꿀 수 있고 현재 장면은 유지한다.
- 자동 촤르륵, 먼지 이동, 흔들림, 시차 효과를 모두 중단할 수 있다.
- 기능 의미는 애니메이션에만 의존하지 않는다.

### FR-13 완주

- 점수, 속도, 다른 아이 비교를 표시하지 않는다.
- 이야기 한 줄, 발견한 핵심 단서, 다시 볼 장면, 다음 사건 예고 중 최대 네 요소만 보여준다.
- 한 문장 회상은 건너뛸 수 있다.
- 다음 책이 없으면 없는 책을 암시하지 않고 같은 책 재탐험을 제안한다.

### FR-14 출판 차단

- schema version, 모든 asset 존재, hash 일치, 필수 alt, 오디오 segment, hotspot 대체 경로를 검사한다.
- 실제 외부 자산은 승인 상태가 아니면 production pack에서 제외한다.
- 문화 사실 claim이 있으면 승인된 claim ledger 항목을 요구한다.
- 차단 사유는 파일, 장면, 필드, 해결 방법과 함께 기계 판독 가능한 결과로 남긴다.

## 8. 핵심 사용자 여정

### 8.1 첫 방문

```text
랜딩
-> 오늘의 책 열기
-> 표지 열기
-> 읽기 모드 선택 또는 기본 직접 읽기
-> 첫 장면
```

가입, 별명, 권한 요청, 설치 제안은 이 경로를 막지 않는다.

### 8.2 4장면 완결

```text
사건 인지
-> 핵심 문장 읽기 또는 듣기
-> 빈자리 관찰
-> 발자국 단서 찾기
-> 근거 선택
-> 연결 카드 열기
-> 사건 원인 회상
-> 완주
```

### 8.3 접근성 대체 여정

```text
단순 페이지 보기
-> 현재 장면 설명 듣기
-> 탐색 영역 목록
-> 새, 고양이, 호랑이 발자국 순차 비교
-> 호랑이 발자국 선택
-> 동일한 이야기 피드백
-> 연결 카드
```

대체 여정은 낮은 등급 콘텐츠가 아니며 같은 완료 상태를 만든다.

### 8.4 실패 복구

```text
고해상도 또는 오디오 실패
-> 읽기 상태 보존
-> 정적 이미지와 텍스트 제공
-> 재시도 또는 계속 읽기
-> 복구된 자산만 교체
```

오류 때문에 장면 처음으로 돌아가거나 발견 기록이 사라지면 안 된다.

## 9. 콘텐츠 계약

- V1 본문은 장면당 1개 핵심 목적과 0개 또는 1개 필수 행동을 기본으로 한다.
- 전체 4장면은 350자에서 650자 범위를 초기 가설로 둔다.
- 핵심 어휘는 장면당 최대 2개다.
- 필수 단서는 전체 수직 절편에 1개만 둔다.
- 모든 행동은 `이 행동이 없으면 이야기를 덜 이해하는가`를 통과해야 한다.
- 사실 설명과 허구 사건을 시각적 문구와 데이터 필드로 구분한다.
- AI 생성물은 초안 provenance를 남기고 사람 승인 전 공개 상태가 될 수 없다.

상세 schema와 출판 상태는 `03-bookspec-rights-data-contract.md`가 소유한다.

## 11. 성공과 실패 판정

### 11.1 Phase 0 기술 성공

- fixture BookPack 하나가 schema와 출판 검사를 통과한다.
- 네 가지 완료 상태를 자동화된 브라우저 여정으로 재현한다.
- 렌즈와 페이지 전환 충돌, 오디오 중복, 진행 손실 fixture가 실제 red를 만든다.
- 키보드와 탭만으로 동일한 완주가 가능하다.
- 지원 기기 프로필에서 성능 예산을 측정한다.

### 11.2 보호자 동반 사용성 성공

법적·연구 승인을 받은 뒤에만 측정한다.

- 아이가 60초 안에 첫 이야기를 시작한다.
- 핵심 조작은 성인 직접 지시 없이 수행한다.
- 4장면을 마친 아이가 호랑이의 행동 이유를 단서와 함께 말하거나 고른다.
- 찾기만 반복하고 본문을 지속적으로 건너뛰는 패턴이 지배적이지 않다.
- 멀미, 두려움, 수치심, 경쟁 압박 신고가 없다.

작은 표본의 백분율을 시장 성과처럼 발표하지 않는다. 행동 관찰과 실패 이유를 먼저 기록한다.

### 11.3 실패와 전환

| 관찰 | 판정 | 다음 행동 |
|---|---|---|
| 페이지 물성이 느리고 혼란만 줌 | `improve` 또는 `revert` | 단순 전환을 기본으로 바꿈 |
| 렌즈가 발견되지 않음 | `improve` | 손잡이와 첫 장면 시각 단서 수정 |
| 읽기를 건너뛰고 찾기만 함 | `repair` | 행동 잠금과 장면 목적 재설계 |
| 실제 유물 카드가 오해를 만듦 | `repair` | 사실·허구 표기와 카드 시점 수정 |
| 정적 읽기보다 회상이 낮음 | `revert` 후보 | 상호작용 수 축소, 제품 가설 재검토 |
| 완결 루프가 성립 | `expand` | 10~12장면 한 권으로 확장 |

## 12. 사업 범위와 확장 가정

V1은 수익화를 구현하지 않는다. 다만 다음 가설을 순서대로 검증한다.

1. 무료 완전 체험 한 권이 보호자 신뢰와 재방문을 만든다.
2. 보호자는 권수보다 고품질 낭독, 재독 단서, 오프라인, 대화 인사이트에 비용을 낸다.
3. 학교는 학생 이메일 없는 학급 배포와 수업안에 비용을 낸다.
4. 기관은 소장품별 이야기 제작과 방문 전후 프로그램에 비용을 낸다.
5. 제작자는 BookSpec 검증과 Scene Studio를 통해 반복 제작 비용을 줄인다.

가격, 구독 주기, B2B 단가는 인터뷰와 실제 제작원가 없이 정하지 않는다. 공공누리 원본 자체를 잠가 파는
것이 아니라 편집, 낭독, 상호작용, 오프라인, 운영 도구에서 가치를 만든다.

## 13. 제품 원칙

1. 책이 먼저고 상호작용은 이해를 돕는다.
2. 조용하지만 지루하지 않다.
3. 화면은 손으로 만지는 도구처럼 보이되 기능은 표준 제어로도 가능하다.
4. 아이에게 선택권을 주지만 한 장면의 주 행동은 하나다.
5. 실패를 벌하지 않고 힌트 사용을 낙인찍지 않는다.
6. 개인정보를 더 모으기보다 제품을 단순하게 만든다.
7. 출처, 이용조건, 사실과 허구의 구분은 제품 기능이다.
8. 계정과 서버가 없어도 첫 독서 가치는 완결된다.
9. 실제 아동과 문화유산에 관한 최종 판단은 승인된 사람이 맡는다.
10. 기능 수보다 다시 읽을 이유가 있는 한 장면의 품질을 우선한다.

## 14. 출시 차단 조건

다음 중 하나라도 참이면 공개하지 않는다.

- 외부 자산의 출처, 이용조건, 변경 허용, 승인자가 불명확하다.
- 실제 유물과 허구 삽화가 구분되지 않는다.
- 드래그 없이는 필수 단서를 찾을 수 없다.
- 키보드 초점이 책 애니메이션 뒤에 갇힌다.
- 오디오가 장면 전환 뒤 중복 재생된다.
- 실패 시 아이의 진행이 조용히 사라진다.
- 제3자 광고, 맞춤형 광고, 불필요한 행동 추적 SDK가 포함된다.
- 개인정보 삭제 경로 없이 계정 또는 입력 저장이 활성화된다.
- 실제 아동 연구가 보호자 동의와 삭제 계획 없이 시작된다.
- fixture 또는 미검수 AI 생성물을 실제 문화유산 사실처럼 표시한다.

## 15. 최종 V1 완료 정의

V1 계획은 다음을 모두 만족할 때만 구현 완료로 전환한다.

1. 4장면 수직 절편이 지원 브라우저에서 실제로 돈다.
2. 읽기, 찾기, 추론, 연결, 완주 상태가 같은 journey ID 안에서 한 번씩만 확정된다.
3. 포인터, 키보드, 동작 줄이기, 선형 대체 탐색 여정이 통과한다.
4. schema, 권리, 접근성, 성능, offline, 오류 복구 게이트가 blocking CI에 등록된다.
5. 실제 사용 자산의 권리와 문화 사실이 사람에게 승인된다. fixture 데모만 공개하면 해당 사실을 명시한다.
6. 승인된 프로토콜의 사용성 연구가 완료되거나, 연구 전 기술 데모임을 공개 범위에서 명시한다.
7. 확인된 현재 명령과 구조를 `docs/**`에 반영한다.
8. `10-progress-decision-ledger.md`에 `expand`, `improve`, `repair`, `revert` 판정을 기록한다.
9. 이 initiative 폴더를 삭제해 미래 계획이 현재 정본으로 남지 않게 한다.
