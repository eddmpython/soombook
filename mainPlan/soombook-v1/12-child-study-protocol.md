# 12. Child Study Protocol Draft

상태: 초안, 미승인, 실제 아동 모집과 기록 금지

이 문서는 기술 체험판 뒤 보호자 동반 사용성 연구를 검토하기 위한 최소 protocol 초안이다. 법률 의견서나
IRB 승인서가 아니며 OG-06 승인 전에는 아동에게 제품을 시험시키거나 데이터를 기록하지 않는다.

## 연구 질문

1. 초등 3학년 아이가 도움 없이 시작 행동을 찾는가.
2. 세 길에서 발자국 크기와 풀잎 방향 두 단서를 실제로 비교하는가.
3. 오답 뒤 낙인 없이 단서로 돌아와 다시 시도하는가.
4. 이야기와 현실 질문 카드의 차이를 이해하는가.
5. 회상 또는 보물 마무리를 압박 없이 선택하는가.

교육 효과, 장기 독해 향상, 문화 지식 향상은 이 짧은 사용성 연구가 답하지 않는다.

## 참여와 중단

- 대상은 초등학교 3학년 연령대와 보호자다.
- 모집 수, 장소, 보상, 기록 방식은 연구 책임자가 승인본에 기입한다.
- 보호자 동의와 별도로 아이가 이해할 수 있는 말로 참여 의사를 확인한다.
- 아이가 싫다고 말하거나 몸짓으로 거부하면 즉시 중단한다.
- 피로, 불안, 반복 실패, 보호자 요청, 기술 오류가 생기면 연구자가 중단한다.
- 학교 성적, 진단, 불이익, 제품 보상과 참여를 연결하지 않는다.

## 최소 수집

승인 전 수집량은 0이다. 승인 뒤에도 다음보다 넓히지 않는다.

| 항목 | 기본 결정 |
|---|---|
| 이름, 연락처 | 제품과 관찰 기록에 저장하지 않음 |
| 자유 답안 원문 | 저장하지 않음 |
| 음성·영상 | 기본 수집하지 않음. 필요하면 별도 근거와 동의 재승인 |
| 정확한 시각·포인터 궤적 | 저장하지 않음 |
| 단계 결과 | 세션 단위 익명 관찰표에 첫 막힘 단계만 기록 검토 |
| 기기 | 넓은 기기 종류와 접근성 설정만 기록 검토 |
| 보호자 메모 | 개인 식별 내용을 제거한 요약만 검토 |

식별 가능한 동의 원본과 연구 기록은 분리 보관한다. public repository, GitHub issue, screenshot과 앱
localStorage에 넣지 않는다.

## 진행 절차

1. 보호자에게 목적, 범위, 수집하지 않는 정보, 중단, 삭제, 문의를 설명한다.
2. 아이에게 `해 보고 싶지 않으면 언제든 멈춰도 돼요`라고 설명하고 동의를 확인한다.
3. 연구자는 기기와 접근성 설정만 준비하고 첫 화면을 보여 준다.
4. 아이가 요청하기 전에는 정답이나 제어 위치를 알려 주지 않는다.
5. 막히면 시간보다 행동을 우선해 관찰하고 승인된 중립 질문만 사용한다.
6. 완주 여부와 관계없이 아이에게 실패 표현이나 비교를 하지 않는다.
7. 종료 직후 보호자와 아이에게 기록 범위와 삭제 요청 방법을 다시 알린다.

허용할 중립 질문 후보:

- `지금 무엇을 해 보고 싶나요?`
- `어디가 헷갈렸나요?`
- `이 단서는 무엇을 알려 주나요?`
- `그만하고 싶으면 바로 말해 주세요.`

## 보존과 삭제

- 보존 기간은 승인자가 목적에 필요한 최소 기간으로 정한다.
- 참여 철회와 삭제 요청 경로를 동의 전에 제공한다.
- 식별 정보, 동의 원본, 익명 관찰을 서로 다른 접근 권한으로 둔다.
- 삭제 실행자, 범위, 백업 반영 시점을 기록한다.
- 연구 종료 또는 중단 시 미사용 원자료를 삭제하고 집계만 남길지 승인자가 판정한다.

## 승인 전 필수 결정

1. 연구 책임자와 개인정보 책임자.
2. 모집 수, 장소, 보상과 이해상충.
3. 보호자 동의문과 아동 동의문.
4. 수집 항목, 저장 위치, 접근자, 보존 기간, 삭제 SLA.
5. 사고, 불편, 민원과 철회 대응.
6. 결과가 확장, 개선, 수리, 철회 중 어떤 판정에 쓰이는지.
7. 실제 문화자산과 음성의 권리·문화·교육 승인 상태.

이 일곱 항목이 승인 기록으로 연결되기 전에는 연구를 시작하지 않는다.
